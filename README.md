# Мобильное приложение под Android для идентификации человека по радужке глаз.

Выполнено в Android Studio.

В корневой папке телефона создается папка IrisRecognition (создается автоматически, однако можно создать самостоятельно). В данную папку помещаются фотографии радужки. Конечно, ввиду ограничений камеры телефона, качество фото, освещение, окружающая среда влияют на предсказание модели.


Для обнаружения глаза на фото использована предобученная модель - **каскадный классификатор Хаара** (URL: https://github.com/austinjoyal/haar-cascade-files/blob/master/haarcascade_eye.xml). Внутри обнаруженной области глаза применяется пороговое преобразование для выделения темной области радужки. Используется поиск контуров (Imgproc.findContours) для нахождения замкнутых областей на бинарном изображении. Вычисляются моменты контура (Imgproc.moments) для определения центра радужки. Область радужки (ROI – Region Of Interest) извлекается для дальнейшей обработки. Извлеченное изображение радужки преобразуется в формат Bitmap. Изображение масштабируется до размера 96×96. Используется предварительно обученная легковесная нейронная сеть **MobileNetV2**, чтобы преобразовать изображение радужки в вектор признаков (эмбеддинг) размером 1×1280. Этот вектор компактно представляет уникальные характеристики радужки.

Для текущего кадра вычисляется вектор признаков радужки. Затем он сравнивается со всеми сохраненными векторами из emb с помощью вычисления косинусного сходства – метода вычисления сходства двух векторов. Если максимальное косинусное сходство превышает пороговое значение (выбрано значение 0,7), пользователь считается идентифицированным. Имя пользователя, соответствующее наиболее похожему сохраненному образцу, отображается на экране. В противном случае отображается «Unknown».
